## What's new

A large model is no longer marked "Too large" just because the file is close to your memory. The app, the project site, and this release use the same version string.

- Qwen 2.5 32B on a 24 GB Mac is a tight fit, and you can still install it. The card estimates runtime memory from the model file, quantization, and the context length the app actually runs.
- Fit labels are Excellent, Good, Tight, May run slowly, and Unsupported. Install stays available unless the machine or backend cannot run the model. Low free memory warns you to close other apps without blocking the download.
- Details show the runtime range, configured context, unified or system memory, and what is free right now. A guessed speed says Estimated. A measured run says Measured.
- The sidebar and Settings show this build's version, such as 0.1.0-alpha.24. The project site header shows the current public release.

### Notes

- Restart the app to pick up this build.
- The speed on a model card is an estimate until you have run that model on this computer.

## What's new

General Assistant can answer questions that need current information, without a tools lesson.

- Ask about today's weather, a recent release, or a documentation page. The assistant searches the web and can open a page, then answers in plain language.
- While that happens, chat shows a short status such as "Searching the web…". Raw function-call JSON stays out of the conversation. "Used N tools" expands the activity.
- Assistant replies render as Markdown, so links, lists, headings, and code look like a normal chat.
- Internet, Files, Shell, and Git are capabilities. Turning one on lets that model use the tools in the group without another approval prompt. A profile you already set to Ask or Deny keeps that choice. An untouched General Assistant is updated on the next launch.
- With Run on set to Automatic, a live question prefers an installed model that can call tools.
- Model cards note whether a model can use tools. If the current model cannot do what you asked, chat offers a tool-capable model or Enable Internet.
- Advanced users can open Tools to search, inspect, enable, disable, and test individual tools. Diagnostics lists recent tool activity.

### Notes

- Restart the app once so an existing General Assistant picks up web search.
- Search reads public DuckDuckGo results. There is no separate weather service.
- A model that cannot call tools still cannot browse.

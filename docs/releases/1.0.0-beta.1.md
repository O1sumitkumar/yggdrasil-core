## What's new

This is the first 1.0 beta: 1.0.0-beta.1.

- If a model stops responding during chat, Yggdrasil stops that process and tells you in the conversation. Any reply already received stays on screen, and you can retry or switch models. The model is not restarted automatically.
- Installing a model marked Tight fit asks you to confirm first. Cancel leaves it uninstalled. Installed and running models still show a Tight fit label.
- This build uses App Store version 1.0, matching the store listing.

### Notes

- Restart the app to pick up this build.
- A model that uses most of this computer's memory may still stop under a heavy reply. Choose a smaller model if that happens.

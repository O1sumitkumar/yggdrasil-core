## What's new

Documentation now follows each app release automatically.

- The public guide covers installation, models, chat, tools, paired computers, Team, API access, settings, and troubleshooting.
- A version selector keeps instructions matched to the installed app, with permanent links to older guides.
- Successful releases publish their own documentation snapshot to the public releases repository. The website refreshes its version list without another deployment.

### Notes

- App behavior is unchanged from alpha.27. This release adds documentation and release automation.
- Documentation content is maintained alongside app changes and frozen when a release ships.

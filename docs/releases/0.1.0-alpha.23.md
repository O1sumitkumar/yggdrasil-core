## What's new

You can pick the model in chat, and a live question reads the page instead of handing you a list of sites.

- The model menu sits in the composer next to Profile and Run on. The choice stays with the chat.
- While a reply is in progress, three dots show with the current status, such as "Searching the web…". Once words arrive, a caret blinks at the end.
- A question that needs current information searches, then opens a page. Weather also reads a short report with temperature, conditions, humidity, and wind, then answers from that instead of listing forecast websites.

### Notes

- Restart the app to pick up this build.
- The weather line comes from a public forecast page. The reply includes that link.

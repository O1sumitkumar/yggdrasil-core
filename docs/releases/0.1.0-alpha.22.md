## What's new

Chat stays with the newest message, and shows how full the model's context is.

- While a reply is coming in, the transcript follows the latest content. Scroll up and following pauses. A small Latest button jumps back to the end. Sending a message pins the view to the latest turn again.
- A ring beside Send shows how much of this model's context the chat is using. Open it for the split: instructions, tools, conversation, and tool results. The total is the tokens the model actually used on the last reply.
- Earlier messages in this chat stay in that conversation until they no longer fit. The newest ones are kept.
- Local models run with an 8.2K context, or a smaller catalog window when the model is smaller than that. The ring uses that running limit.

### Notes

- The ring is empty until a reply finishes. It belongs to the open chat. Switching chats clears it until the next reply there.
